Agri Drone Workshop: Mission Planner to Python Control

A Step-by-Step Build Cookbook — Setup, SITL, Missions, Python Control, Survey Grids & Geofence

How This Cookbook Works

We are not going to jump straight to "fly an autonomous spray mission." That is how you end up staring at a disarmed drone with no idea which step broke it.

Instead we build one capability at a time, watch it work in simulation, and only then add the next one. You first look around Mission Planner, start the simulator and fly a waypoint mission by hand, then check the MAVLink heartbeat and drive the same simulated drone from Python — manual control first, then autonomous missions, then survey grids and a geofence. Each of the four scripts in this project folder is the heart of its own phase — shown here exactly as it ships.

Prerequisites — Python 3.10 & Libraries

Do this once, before the workshop starts. The Python scripts in Phases 3-7 need Python 3.10 plus two libraries. Follow the steps in order and install each library on its own so you can see exactly which one fails.

Mission Planner is Windows software Download and install it from ardupilot.org/planner/docs/mission-planner-installation.html (the installer MissionPlanner-latest.msi). The commands below are shown for Windows first, with macOS / Linux alternatives.

See what you already have

If you see Python 3.10.x, skip to Step 3. py -0 lists every version installed side by side on Windows. If Python is missing, or you only have another version, install 3.10.

Common Errors
  • python is not recognized: reinstall 3.10 and tick “Add python.exe to PATH”, or use py -3.10.
  • pip installs but the import fails: pip and the interpreter are different Pythons — re-run with python -m pip install ... in the terminal that shows 3.10.
  • Error building a wheel for pygame: you are almost certainly on a too-new Python (e.g. 3.14). Switch to 3.10 (Step 2).

Phase 2 — Waypoint Navigation in Mission Planner

Before any code: learn how a mission flies. You plan a route on the map, then let the autopilot navigate it waypoint by waypoint.

2a — Plan the Mission

Phase 2a

Goal

Hand-draw a complete mission in the Plan tab: climb, visit a few points, come home. No flying yet — just the plan.

Walkthrough

  • Open the Plan tab, centred near the SITL home position.
  • Add a TAKEOFF block first. Right-click the map → Takeoff, set altitude (e.g. 20 m). This must be mission item 1.
  • Add waypoints by clicking. Left-click the map a few times — each click drops a WAYPOINT row. Place 3–5 in a rough loop and set an altitude for each.
  • End with RTL. Add RETURN_TO_LAUNCH as the last row (right-click → RTL) — it brings the drone home and lands it.
  • Click Write to upload the mission, then Read to confirm it round-trips.

2b — Fly the Mission & Auto-Disarm

Phase 2b

Goal

Run the mission you planned and watch the drone fly itself.

Walkthrough

  • Switch to the Data tab, open the Actions sub-tab.
  • Click Arm/Disarm to arm (check pre-arm messages if it refuses — usually GPS settling).
  • Select Mission Start and set its action (start from the first item); send it.
  • Set the flight mode to Auto.
  • Confirm the drone is armed, then watch: it takes off, flies each waypoint in order (active leg highlights, HUD updates), then RTLs.
  • After RTL lands, the drone disarms automatically — you do not disarm it yourself.

The Actions sub-tab: Arm/ Disarm, Set Mode (Auto), Auto, RTL, Resume Mission.

✅ Checkpoint

The drone climbs, tracks every waypoint, returns to launch, lands, and disarms on its own. The Messages tab shows mission-item progress.

Common Errors
  • Arms but never takes off: mode was not set to Auto, or Mission Start was not sent.
  • Disarms right after takeoff: throttle-confirm issue with no RC — exactly what AUTO_OPTIONS = 3 fixes in waypoint.py.
  • "Mission rejected": no TAKEOFF as item 1, or the mission was never written.

Challenge — Change the Altitude

Challenge

Change the Altitude

Take the mission you just flew and change its altitude — no other edits.

  • In the Plan tab, edit the Alt column of the TAKEOFF row and every WAYPOINT row (e.g. 20 m → 40 m).
  • Write the mission, then Arm, Mission Start, mode Auto again.
  • Watch the altitude on the HUD — the drone should now climb to and cruise at the new height.

Phase 3 — MAVLink & Heartbeat

Phase 3
heartbeat.py

Goal

The "hello world" of MAVLink: open a connection to the running SITL, wait for its heartbeat, and print the system and component IDs. If this passes, every other script in the workshop can talk to the drone.

A Little Theory

  • Every MAVLink vehicle broadcasts a HEARTBEAT message about once a second — it is how a ground station knows something is alive on the link.
  • mavutil.mavlink_connection("tcp:127.0.0.1:5762") opens the link to SITL.
  • master.wait_heartbeat() blocks until the first heartbeat arrives and records the vehicle's target_system / target_component — the address every later command is sent to.

Run it

bashpython heartbeat.py

Full Code — heartbeat.py

pythonfrom pymavlink import mavutil

print("Connecting...")

master = mavutil.mavlink_connection(
    "tcp:127.0.0.1:5762"
)

print("Waiting for heartbeat...")

print(master.wait_heartbeat())

print("HEARTBEAT RECEIVED!")
print("System ID:", master.target_system)
print("Component ID:", master.target_component)

Expected output of python heartbeat.py

✅ Checkpoint

The console prints HEARTBEAT RECEIVED! with a System ID (usually 1) and a Component ID.

Common Errors
  • Connection refused / hangs on "Waiting for heartbeat": SITL is not running, or it is not on port 5762 — restart SITL from the Simulation tab (Phase 1).
  • ModuleNotFoundError: pymavlink: you are on the wrong interpreter or skipped the install — see Prerequisites: select Python 3.10, then run pip install "pymavlink>=2.4.40".

Phase 4 — Python Control: Arm, Takeoff, Land, Disarm

Phase 4
control.py

Goal

Interactive GUIDED-mode control. A menu lets you arm, take off to a set altitude, land, and disarm. It also carries body-frame velocity helpers (move_forward, move_right, yaw_left, …) — the Python route to flying a shape by hand.

A Little Theory

  • set_mode(master, "GUIDED") puts the drone in a mode that accepts point-and-velocity commands from a companion computer.
  • MAV_CMD_COMPONENT_ARM_DISARM arms/disarms; MAV_CMD_NAV_TAKEOFF climbs to a target altitude; MAV_CMD_NAV_LAND descends.
  • wait_for_ack() reads back COMMAND_ACK so you know whether each command was accepted or rejected.
  • The move_* / yaw_* helpers stream SET_POSITION_TARGET_LOCAL_NED velocity messages at 10 Hz for a few seconds, then send a zero-velocity stop.

Run it

bashpython control.py

Full Code — control.py

python
import time

from pymavlink import mavutil

# ---------------------------------------------------------------------------
# CONFIG
# ---------------------------------------------------------------------------
CONNECTION_STRING = "tcp:127.0.0.1:5762"

TAKEOFF_ALTITUDE_M = 100.0
ALTITUDE_TOLERANCE_M = 0.5
VELOCITY_MPS = 1.0          # speed used for move_* helpers
YAW_RATE_DEG_S = 20.0       # yaw rate used for yaw_* helpers
MOVE_DURATION_SEC = 3.0     # how long each move_* call runs before stopping


# ---------------------------------------------------------------------------
# CONNECTION
# ---------------------------------------------------------------------------
def connect():
    print(f"[CONNECT] Connecting to {CONNECTION_STRING} ...")
    master = mavutil.mavlink_connection(CONNECTION_STRING)
    print("[WAIT] Waiting for heartbeat...")
    master.wait_heartbeat(timeout=30)
    print(f"[OK] Heartbeat received. System {master.target_system}, "
          f"Component {master.target_component}")
    request_data_streams(master)
    return master


def request_data_streams(master, rate_hz=4):
    """Ask the vehicle to stream position/attitude/etc. at a known rate.
    Without this, messages like GLOBAL_POSITION_INT may arrive too rarely
    (or not at all) for altitude/position monitoring to work reliably."""
    master.mav.request_data_stream_send(
        master.target_system, master.target_component,
        mavutil.mavlink.MAV_DATA_STREAM_ALL,
        rate_hz,
        1,  # start streaming
    )
    print(f"[OK] Requested data streams at {rate_hz} Hz")


# ---------------------------------------------------------------------------
# COMMAND_ACK HELPER
# ---------------------------------------------------------------------------
def wait_for_ack(master, command_id, timeout=5):
    """Wait for a COMMAND_ACK matching command_id. Returns True if accepted.
    Also prints any STATUSTEXT messages seen in the meantime, since
    ArduPilot often explains a REJECTED/FAILED result through those."""
    start = time.time()
    while time.time() - start < timeout:
        msg = master.recv_match(type=["COMMAND_ACK", "STATUSTEXT"], blocking=True, timeout=timeout)
        if msg is None:
            continue
        if msg.get_type() == "STATUSTEXT":
            print(f"[STATUS] {msg.text}")
            continue
        if msg.command == command_id:
            accepted = msg.result == mavutil.mavlink.MAV_RESULT_ACCEPTED
            if accepted:
                print(f"[ACK] Command {command_id} ACCEPTED")
            else:
                print(f"[ACK] Command {command_id} REJECTED "
                      f"(result={msg.result})")
            return accepted
    print(f"[WARN] No ACK received for command {command_id} within {timeout}s")
    return False


# ---------------------------------------------------------------------------
# MODE / ARM / DISARM
# ---------------------------------------------------------------------------
def set_mode(master, mode_name, timeout=10):
    """Change flight mode by name (e.g. 'GUIDED', 'LAND', 'RTL')."""
    mode_mapping = master.mode_mapping()
    if mode_mapping is None or mode_name not in mode_mapping:
        print(f"[ERROR] Unknown mode '{mode_name}'. "
              f"Available: {list(mode_mapping.keys()) if mode_mapping else 'none'}")
        return False

    mode_id = mode_mapping[mode_name]
    master.mav.set_mode_send(
        master.target_system,
        mavutil.mavlink.MAV_MODE_FLAG_CUSTOM_MODE_ENABLED,
        mode_id,
    )

    start = time.time()
    while time.time() - start < timeout:
        msg = master.recv_match(type="HEARTBEAT", blocking=True, timeout=timeout)
        if msg is None:
            continue
        current_mode = mavutil.mode_string_v10(msg)
        if current_mode == mode_name:
            print(f"[OK] Mode set to {mode_name}")
            return True
    print(f"[ERROR] Failed to confirm mode change to {mode_name}")
    return False


def arm(master, timeout=10):
    print("[ARM] Arming vehicle...")
    master.mav.command_long_send(
        master.target_system, master.target_component,
        mavutil.mavlink.MAV_CMD_COMPONENT_ARM_DISARM,
        0,
        1, 0, 0, 0, 0, 0, 0,
    )
    accepted = wait_for_ack(master, mavutil.mavlink.MAV_CMD_COMPONENT_ARM_DISARM, timeout)
    if not accepted:
        return False

    # Confirm actually armed via heartbeat base_mode flag
    start = time.time()
    while time.time() - start < timeout:
        msg = master.recv_match(type="HEARTBEAT", blocking=True, timeout=timeout)
        if msg is None:
            continue
        armed = bool(msg.base_mode & mavutil.mavlink.MAV_MODE_FLAG_SAFETY_ARMED)
        if armed:
            print("[OK] Vehicle is ARMED")
            return True
    print("[ERROR] Vehicle did not confirm armed state")
    return False


def disarm(master, timeout=10):
    print("[DISARM] Disarming vehicle...")
    master.mav.command_long_send(
        master.target_system, master.target_component,
        mavutil.mavlink.MAV_CMD_COMPONENT_ARM_DISARM,
        0,
        0, 0, 0, 0, 0, 0, 0,
    )
    accepted = wait_for_ack(master, mavutil.mavlink.MAV_CMD_COMPONENT_ARM_DISARM, timeout)
    if not accepted:
        return False

    start = time.time()
    while time.time() - start < timeout:
        msg = master.recv_match(type="HEARTBEAT", blocking=True, timeout=timeout)
        if msg is None:
            continue
        armed = bool(msg.base_mode & mavutil.mavlink.MAV_MODE_FLAG_SAFETY_ARMED)
        if not armed:
            print("[OK] Vehicle is DISARMED")
            return True
    print("[ERROR] Vehicle did not confirm disarmed state")
    return False


# ---------------------------------------------------------------------------
# TAKEOFF / LAND
# ---------------------------------------------------------------------------
def get_relative_altitude(master, timeout=2):
    """Drain any buffered messages and return the most recent altitude."""
    latest = None
    end_time = time.time() + timeout
    while time.time() < end_time:
        msg = master.recv_match(type="GLOBAL_POSITION_INT", blocking=True, timeout=0.5)
        if msg is not None:
            latest = msg.relative_alt / 1000.0  # mm -> m
    return latest


def get_landed_state(master, timeout=3):
    """Returns a readable landed state string from EXTENDED_SYS_STATE, or
    None if the message wasn't received (older firmware may not send it)."""
    states = {
        0: "UNDEFINED",
        1: "ON_GROUND",
        2: "IN_AIR",
        3: "TAKEOFF",
        4: "LANDING",
    }
    msg = master.recv_match(type="EXTENDED_SYS_STATE", blocking=True, timeout=timeout)
    if msg is None:
        return None
    return states.get(msg.landed_state, f"UNKNOWN ({msg.landed_state})")


def takeoff(master, altitude=TAKEOFF_ALTITUDE_M, timeout=None):
    # Scale the timeout with altitude so higher targets get enough time to
    # climb (observed sim climb rate is roughly 2-3 m/s).
    if timeout is None:
        timeout = max(30, int(altitude / 2.0) + 20)

    print(f"[TAKEOFF] Requesting takeoff to {altitude} m "
          f"(timeout {timeout}s)...")

    landed_state = get_landed_state(master)
    print(f"[CHECK] Landed state before takeoff: {landed_state}")
    if landed_state == "IN_AIR":
        print("[ERROR] Vehicle already thinks it's airborne — land it fully "
              "first (Mission Planner Actions tab -> LAND, wait for "
              "DISARMED) before retrying takeoff.")
        return False

    master.mav.command_long_send(
        master.target_system, master.target_component,
        mavutil.mavlink.MAV_CMD_NAV_TAKEOFF,
        0,
        0, 0, 0, 0, 0, 0, altitude,
    )
    accepted = wait_for_ack(master, mavutil.mavlink.MAV_CMD_NAV_TAKEOFF, timeout=5)
    if not accepted:
        return False

    print("[TAKEOFF] Climbing... monitoring altitude")
    start = time.time()
    while time.time() - start < timeout:
        alt = get_relative_altitude(master)
        if alt is None:
            continue
        print(f"        Altitude: {alt:.2f} m")
        if alt >= altitude - ALTITUDE_TOLERANCE_M:
            print(f"[OK] Reached target altitude ({alt:.2f} m)")
            return True
    print("[ERROR] Takeoff did not reach target altitude in time — the "
          "vehicle is likely still airborne/climbing. Use menu option 3 "
          "(Land) now before trying option 2 again.")
    return False


def land(master, timeout=60):
    print("[LAND] Requesting land...")
    master.mav.command_long_send(
        master.target_system, master.target_component,
        mavutil.mavlink.MAV_CMD_NAV_LAND,
        0,
        0, 0, 0, 0, 0, 0, 0,
    )
    accepted = wait_for_ack(master, mavutil.mavlink.MAV_CMD_NAV_LAND, timeout=5)
    if not accepted:
        return False

    print("[LAND] Descending... waiting for disarm")
    start = time.time()
    while time.time() - start < timeout:
        msg = master.recv_match(type="HEARTBEAT", blocking=True, timeout=5)
        if msg is None:
            continue
        armed = bool(msg.base_mode & mavutil.mavlink.MAV_MODE_FLAG_SAFETY_ARMED)
        alt = get_relative_altitude(master, timeout=1)
        if alt is not None:
            print(f"        Altitude: {alt:.2f} m, Armed: {armed}")
        if not armed:
            print("[OK] Landed and disarmed")
            return True
    print("[WARN] Land timeout reached — vehicle may still be armed")
    return False


# ---------------------------------------------------------------------------
# VELOCITY CONTROL (body frame: x=forward, y=right, z=down)
# ---------------------------------------------------------------------------
def send_velocity_body(master, vx, vy, vz, yaw_rate=0.0):
    """Send one SET_POSITION_TARGET_LOCAL_NED velocity command (body frame)."""
    type_mask = (
        0b0000_0111_1100_0111  # ignore position + accel, use vel + yaw_rate
    )
    master.mav.set_position_target_local_ned_send(
        0,                                          # time_boot_ms (ignored)
        master.target_system, master.target_component,
        mavutil.mavlink.MAV_FRAME_BODY_OFFSET_NED,
        type_mask,
        0, 0, 0,          # position (ignored)
        vx, vy, vz,       # velocity m/s
        0, 0, 0,          # acceleration (ignored)
        0,                # yaw (ignored)
        yaw_rate,         # yaw rate rad/s
    )


def _stream_velocity(master, vx, vy, vz, yaw_rate=0.0, duration=MOVE_DURATION_SEC):
    """Stream a velocity command at 10 Hz for `duration` seconds, then stop."""
    end_time = time.time() + duration
    while time.time() < end_time:
        send_velocity_body(master, vx, vy, vz, yaw_rate)
        time.sleep(0.1)
    stop(master)


def move_forward(master, speed=VELOCITY_MPS, duration=MOVE_DURATION_SEC):
    print(f"[MOVE] Forward @ {speed} m/s for {duration}s")
    _stream_velocity(master, speed, 0, 0, duration=duration)


def move_backward(master, speed=VELOCITY_MPS, duration=MOVE_DURATION_SEC):
    print(f"[MOVE] Backward @ {speed} m/s for {duration}s")
    _stream_velocity(master, -speed, 0, 0, duration=duration)


def move_left(master, speed=VELOCITY_MPS, duration=MOVE_DURATION_SEC):
    print(f"[MOVE] Left @ {speed} m/s for {duration}s")
    _stream_velocity(master, 0, -speed, 0, duration=duration)


def move_right(master, speed=VELOCITY_MPS, duration=MOVE_DURATION_SEC):
    print(f"[MOVE] Right @ {speed} m/s for {duration}s")
    _stream_velocity(master, 0, speed, 0, duration=duration)


def move_up(master, speed=VELOCITY_MPS, duration=MOVE_DURATION_SEC):
    print(f"[MOVE] Up @ {speed} m/s for {duration}s")
    # NED frame: negative z = up
    _stream_velocity(master, 0, 0, -speed, duration=duration)


def move_down(master, speed=VELOCITY_MPS, duration=MOVE_DURATION_SEC):
    print(f"[MOVE] Down @ {speed} m/s for {duration}s")
    _stream_velocity(master, 0, 0, speed, duration=duration)


def yaw_left(master, rate_deg_s=YAW_RATE_DEG_S, duration=MOVE_DURATION_SEC):
    print(f"[YAW] Left @ {rate_deg_s} deg/s for {duration}s")
    rate_rad_s = -abs(rate_deg_s) * 3.14159265 / 180.0
    _stream_velocity(master, 0, 0, 0, yaw_rate=rate_rad_s, duration=duration)


def yaw_right(master, rate_deg_s=YAW_RATE_DEG_S, duration=MOVE_DURATION_SEC):
    print(f"[YAW] Right @ {rate_deg_s} deg/s for {duration}s")
    rate_rad_s = abs(rate_deg_s) * 3.14159265 / 180.0
    _stream_velocity(master, 0, 0, 0, yaw_rate=rate_rad_s, duration=duration)


def stop(master):
    """Send a zero-velocity command to halt movement."""
    send_velocity_body(master, 0, 0, 0, 0)


# ---------------------------------------------------------------------------
# INTERACTIVE MENU
# ---------------------------------------------------------------------------
def print_menu():
    print("\n=================================")
    print(" 1 - Arm")
    print(f" 2 - Takeoff to {TAKEOFF_ALTITUDE_M} m")
    print(" 3 - Land")
    print(" 4 - Disarm")
    print(" 5 - Exit")
    print("=================================")


def main():
    master = connect()

    while True:
        print_menu()

Phase 5 — Autonomous Waypoint Mission

Phase 5
waypoint.py

Goal

Do Phase 2 in software, fully autonomous: build a mission (home placeholder → TAKEOFF → four WAYPOINTs that form a square → RTL), upload it over MAVLink, arm, switch to AUTO, and monitor progress until the vehicle disarms after RTL.

A Little Theory

  • AUTO_OPTIONS = 3 allows arming from AUTO and a throttle-free takeoff — without it a no-RC scripted AUTO mission takes off and immediately disarms.
  • build_mission_items() assembles the item list; seq 0 is a home placeholder ArduPilot overwrites but still requires.
  • upload_mission() answers each MISSION_REQUEST with the matching mission_item_int, then waits for MISSION_ACK.
  • set_current_mission_item(master, 1) makes the mission start at the TAKEOFF item, not seq 0.
  • monitor_mission() prints each MISSION_CURRENT change and altitude until the heartbeat shows disarmed.

from pymavlink import mavutil

# CONFIG
# ---------------------------------------------------------------------------
CONNECTION_STRING = "tcp:127.0.0.1:5762"

WAYPOINT_ACCEPT_RADIUS_M = 2.0  # how close counts as "reached" a waypoint

TAKEOFF_ALTITUDE_M = 20.0

# (latitude, longitude, relative altitude in meters)
WAYPOINTS = [
    (-35.3622, 149.1652, 20.0),
    (-35.3622, 149.1668, 20.0),
    (-35.3642, 149.1668, 20.0),
    (-35.3642, 149.1652, 20.0),
]

# CONNECTION
# ---------------------------------------------------------------------------
def connect():
    print(f"[CONNECT] Connecting to {CONNECTION_STRING} ...")
    master = mavutil.mavlink_connection(CONNECTION_STRING)
    print("[WAIT] Waiting for heartbeat...")
    master.wait_heartbeat(timeout=30)
    print(f"[OK] Heartbeat received. System {master.target_system}, "
          f"Component {master.target_component}")
    master.mav.request_data_stream_send(
        master.target_system, master.target_component,
        mavutil.mavlink.MAV_DATA_STREAM_ALL, 4, 1,
    )
    print("[OK] Requested data streams at 4 Hz")
    return master


def wait_for_ack(master, command_id, timeout=5):
    start = time.time()
    while time.time() - start < timeout:
        msg = master.recv_match(type=["COMMAND_ACK", "STATUSTEXT"], blocking=True, timeout=timeout)
        if msg is None:
            continue
        if msg.get_type() == "STATUSTEXT":
            print(f"[STATUS] {msg.text}")
            continue
        if msg.command == command_id:
            accepted = msg.result == mavutil.mavlink.MAV_RESULT_ACCEPTED
            print(f"[ACK] Command {command_id} "
                  f"{'ACCEPTED' if accepted else f'REJECTED (result={msg.result})'}")
            return accepted
    print(f"[WARN] No ACK for command {command_id} within {timeout}s")
    return False


def get_current_position(master, timeout=5):
    """Returns (lat, lon) in degrees, used as the placeholder home item."""
    msg = master.recv_match(type="GLOBAL_POSITION_INT", blocking=True, timeout=timeout)
    if msg is None:
        print("[WARN] Could not read current position, using (0, 0) as placeholder")
        return 0.0, 0.0
    return msg.lat / 1e7, msg.lon / 1e7


def set_param(master, param_name, value, timeout=5):
    """Set a numeric parameter and wait for the vehicle to confirm it."""
    master.mav.param_set_send(
        master.target_system, master.target_component,
        param_name.encode("utf-8"),
        float(value),
        mavutil.mavlink.MAV_PARAM_TYPE_REAL32,
    )
    start = time.time()
    while time.time() - start < timeout:
        msg = master.recv_match(type="PARAM_VALUE", blocking=True, timeout=timeout)
        if msg is None:
            continue
        received_name = msg.param_id.strip("\x00") if isinstance(msg.param_id, str) else msg.param_id
        if received_name == param_name:
            print(f"[PARAM] {param_name} = {msg.param_value}")
            return True
    print(f"[WARN] No confirmation received for parameter {param_name}")
    return False


def enable_throttle_free_auto_takeoff(master):
    """
    AUTO_OPTIONS bitmask:
        bit 0 (1) - Allow arming from AUTO mode
        bit 1 (2) - Allow takeoff without raising the throttle stick
    Without this, a scripted/companion-computer AUTO mission takeoff will
    enter the takeoff command and then immediately disarm, since ArduCopter
    is waiting for a throttle-stick "confirm launch" that never arrives
    when there's no RC/joystick connected.
    """
    print("[PARAM] Setting AUTO_OPTIONS to allow throttle-free AUTO takeoff...")
    set_param(master, "AUTO_OPTIONS", 3)

# MODE / ARM
# ---------------------------------------------------------------------------
def set_mode(master, mode_name, timeout=10):
    mode_mapping = master.mode_mapping()
    if mode_mapping is None or mode_name not in mode_mapping:
        print(f"[ERROR] Unknown mode '{mode_name}'")
        return False
    mode_id = mode_mapping[mode_name]
    master.mav.set_mode_send(
        master.target_system,
        mavutil.mavlink.MAV_MODE_FLAG_CUSTOM_MODE_ENABLED,
        mode_id,
    )
    start = time.time()
    while time.time() - start < timeout:
        msg = master.recv_match(type=["HEARTBEAT", "STATUSTEXT"], blocking=True, timeout=timeout)
        if msg is None:
            continue
        if msg.get_type() == "STATUSTEXT":
            print(f"[STATUS] {msg.text}")
            continue
        if mavutil.mode_string_v10(msg) == mode_name:
            print(f"[OK] Mode set to {mode_name}")
            return True
    print(f"[ERROR] Failed to confirm mode change to {mode_name}")
    return False


def arm(master, timeout=10):
    print("[ARM] Arming vehicle...")
    master.mav.command_long_send(
        master.target_system, master.target_component,
        mavutil.mavlink.MAV_CMD_COMPONENT_ARM_DISARM,
        0, 1, 0, 0, 0, 0, 0, 0,
    )
    if not wait_for_ack(master, mavutil.mavlink.MAV_CMD_COMPONENT_ARM_DISARM, timeout):
        return False
    start = time.time()
    while time.time() - start < timeout:
        msg = master.recv_match(type=["HEARTBEAT", "STATUSTEXT"], blocking=True, timeout=timeout)
        if msg is None:
            continue
        if msg.get_type() == "STATUSTEXT":
            print(f"[STATUS] {msg.text}")
            continue
        if bool(msg.base_mode & mavutil.mavlink.MAV_MODE_FLAG_SAFETY_ARMED):
            print("[OK] Vehicle is ARMED")
            return True
    print("[ERROR] Vehicle did not confirm armed state")
    return False

# MISSION BUILDING / UPLOAD
# ---------------------------------------------------------------------------
def build_mission_items(home_lat, home_lon, takeoff_alt, waypoints):
    """
    Returns a list of mission item dicts:
      seq 0 -> placeholder home item (ArduPilot overwrites this with the
               actual home position - it must still be sent)
      seq 1 -> NAV_TAKEOFF to takeoff_alt
      seq 2..n -> NAV_WAYPOINT for each user-entered (lat, lon, alt)
      seq n+1 -> NAV_RETURN_TO_LAUNCH (RTL)
    """
    items = []

    # seq 0: home placeholder
    items.append(dict(
        frame=mavutil.mavlink.MAV_FRAME_GLOBAL,
        command=mavutil.mavlink.MAV_CMD_NAV_WAYPOINT,
        current=0, autocontinue=1,
        param1=0, param2=0, param3=0, param4=float("nan"),
        x=int(home_lat * 1e7), y=int(home_lon * 1e7), z=0,
    ))

    # seq 1: takeoff
    items.append(dict(
        frame=mavutil.mavlink.MAV_FRAME_GLOBAL_RELATIVE_ALT,
        command=mavutil.mavlink.MAV_CMD_NAV_TAKEOFF,
        current=0, autocontinue=1,
        param1=0, param2=0, param3=0, param4=float("nan"),
        x=0, y=0, z=takeoff_alt,
    ))

    # seq 2..n: waypoints
    for lat, lon, alt in waypoints:
        items.append(dict(
            frame=mavutil.mavlink.MAV_FRAME_GLOBAL_RELATIVE_ALT,
            command=mavutil.mavlink.MAV_CMD_NAV_WAYPOINT,
            current=0, autocontinue=1,
            param1=0, param2=WAYPOINT_ACCEPT_RADIUS_M, param3=0, param4=float("nan"),
            x=int(lat * 1e7), y=int(lon * 1e7), z=alt,
        ))

    # last: RTL
    items.append(dict(
        frame=mavutil.mavlink.MAV_FRAME_GLOBAL_RELATIVE_ALT,
        command=mavutil.mavlink.MAV_CMD_NAV_RETURN_TO_LAUNCH,
        current=0, autocontinue=1,
        param1=0, param2=0, param3=0, param4=0,
        x=0, y=0, z=0,
    ))

    return items


def upload_mission(master, items, timeout=15):
    n = len(items)
    print(f"[MISSION] Uploading {n} items...")
    master.mav.mission_count_send(master.target_system, master.target_component, n)

    for _ in range(n):
        msg = master.recv_match(
            type=["MISSION_REQUEST_INT", "MISSION_REQUEST"],
            blocking=True, timeout=timeout,
        )
        if msg is None:
            print("[ERROR] No mission item request received - upload failed")
            return False

        seq = msg.seq
        item = items[seq]
        master.mav.mission_item_int_send(
            master.target_system, master.target_component, seq,
            item["frame"], item["command"], item["current"], item["autocontinue"],
            item["param1"], item["param2"], item["param3"], item["param4"],
            item["x"], item["y"], item["z"],
        )
        print(f"        Sent item {seq}: command={item['command']}")

    ack = master.recv_match(type="MISSION_ACK", blocking=True, timeout=timeout)
    if ack is None:
        print("[ERROR] No MISSION_ACK received - upload may have failed")
        return False
    if ack.type == mavutil.mavlink.MAV_MISSION_ACCEPTED:
        print("[OK] Mission upload accepted")
        return True
    print(f"[ERROR] Mission upload rejected (type={ack.type})")
    return False


def set_current_mission_item(master, seq):
    master.mav.mission_set_current_send(master.target_system, master.target_component, seq)
    print(f"[MISSION] Current item set to {seq}")


# ---------------------------------------------------------------------------
# MISSION MONITORING
# ---------------------------------------------------------------------------
def monitor_mission(master, poll_timeout=0.5, overall_timeout=1800):
    """Print progress until the vehicle disarms (RTL landed) or timeout."""
    print("[MONITOR] Mission running - press Ctrl+C to stop watching "
          "(the mission keeps running on the vehicle either way)\n")

    last_seq = None
    start = time.time()

    try:
        while time.time() - start < overall_timeout:
            status_msg = master.recv_match(type="STATUSTEXT", blocking=False)
            if status_msg is not None:
                print(f"[STATUS] {status_msg.text}")

            cur_msg = master.recv_match(type="MISSION_CURRENT", blocking=False)
            if cur_msg is not None and cur_msg.seq != last_seq:
                last_seq = cur_msg.seq
                print(f"[MISSION] Now executing item {last_seq}")

            pos_msg = master.recv_match(type="GLOBAL_POSITION_INT", blocking=False)
            hb_msg = master.recv_match(type="HEARTBEAT", blocking=False)

            if pos_msg is not None:
                alt = pos_msg.relative_alt / 1000.0
                print(f"        Altitude: {alt:.2f} m")

            if hb_msg is not None:
                armed = bool(hb_msg.base_mode & mavutil.mavlink.MAV_MODE_FLAG_SAFETY_ARMED)
                if not armed:
                    print("[OK] Vehicle disarmed - mission (including RTL) complete")
                    return True

            time.sleep(poll_timeout)
    except KeyboardInterrupt:
        print("\n[MONITOR] Stopped watching (mission continues running on the vehicle)")
        return None

    print("[WARN] Monitor timed out before disarm was observed")
    return False

# MAIN
# ---------------------------------------------------------------------------
def main():
    master = connect()
    enable_throttle_free_auto_takeoff(master)

    takeoff_alt = TAKEOFF_ALTITUDE_M
    waypoints = WAYPOINTS

    print(f"\n[MISSION] Takeoff altitude: {takeoff_alt} m")
    print(f"[MISSION] {len(waypoints)} waypoints configured:")
    for i, (lat, lon, alt) in enumerate(waypoints, start=1):
        print(f"        {i}. lat={lat}, lon={lon}, alt={alt} m")

    print("\n[HOME] Reading current position for home placeholder item...")
    home_lat, home_lon = get_current_position(master)
    print(f"        Using ({home_lat:.7f}, {home_lon:.7f})")

    items = build_mission_items(home_lat, home_lon, takeoff_alt, waypoints)

    if not upload_mission(master, items):
        return

    if not set_mode(master, "GUIDED"):
        return

    if not arm(master):
        return

    # Brief settle delay - jumping straight from arm() to AUTO with zero
    # pause can be too fast for the EKF/land-detector to catch up, and has
    # been observed causing an immediate safety disarm. Drain any status
    # messages during this pause so nothing gets missed.
    print("[WAIT] Settling for 3s before starting the mission...")
    settle_end = time.time() + 3
    while time.time() < settle_end:
        msg = master.recv_match(type="STATUSTEXT", blocking=True, timeout=0.5)
        if msg is not None:
            print(f"[STATUS] {msg.text}")

    # Make sure the mission starts at the takeoff item (seq 1), not seq 0
    set_current_mission_item(master, 1)

    if not set_mode(master, "AUTO"):
        return

    print("\n[MISSION] AUTO mode engaged - vehicle will takeoff, fly the "
          "waypoints, then RTL automatically.\n")

    monitor_mission(master)

    print("Waypoint mission script finished.")
    master.close()


if __name__ == "__main__":
    main()

Phase 7 — Geofence

The safety layer around every survey mission: an invisible boundary that flies the drone home if it strays.

Phase 7
geofence.py

Goal

Set an altitude + circular geofence via parameters, arm, take off, then deliberately fly outward past the fence radius and watch the fence action (RTL) trigger and land/disarm the vehicle. This is the safety layer around every survey mission.

A Little Theory

  • FENCE_TYPE is a bitmask (bit0 = max altitude, bit1 = circle, bit2 = polygon); the script uses 0b011 — altitude + circle.
  • FENCE_ALT_MAX, FENCE_RADIUS, FENCE_ACTION (1 = RTL) and FENCE_ENABLE are set with set_param() and read back with get_param().
  • The demo streams a forward velocity to cross the ~60 m radius; ArduPilot then overrides the mode and executes the fence action.
  • FENCE_STATUS carries breach_status / breach_type — print_fence_status() watches for the breach.

def request_message_interval(master, message_id, rate_hz):
    """Explicitly ask for a specific message at a given rate. Some messages

            command=mavutil.mavlink.MAV_CMD_NAV_WAYPOINT,
            current=0, autocontinue=1,
            param1=0, param2=WAYPOINT_ACCEPT_RADIUS_M, param3=0, param4=float("nan"),
            x=int(lat * 1e7), y=int(lon * 1e7), z=alt,
        ))

    items.append(dict(
        frame=mavutil.mavlink.MAV_FRAME_GLOBAL_RELATIVE_ALT,
        command=mavutil.mavlink.MAV_CMD_NAV_RETURN_TO_LAUNCH,
        current=0, autocontinue=1,
        param1=0, param2=0, param3=0, param4=0,
        x=0, y=0, z=0,
    ))

    return items


def upload_mission(master, items, timeout=15):
    n = len(items)
    print(f"[MISSION] Uploading {n} items...")
    master.mav.mission_count_send(master.target_system, master.target_component, n)

    for _ in range(n):
        msg = master.recv_match(
            type=["MISSION_REQUEST_INT", "MISSION_REQUEST"],
            blocking=True, timeout=timeout,
        )
        if msg is None:
            print("[ERROR] No mission item request received - upload failed")
            return False

        seq = msg.seq
        item = items[seq]
        master.mav.mission_item_int_send(
            master.target_system, master.target_component, seq,
            item["frame"], item["command"], item["current"], item["autocontinue"],
            item["param1"], item["param2"], item["param3"], item["param4"],
            item["x"], item["y"], item["z"],
        )
        print(f"        Sent item {seq}: command={item['command']}")

    ack = master.recv_match(type="MISSION_ACK", blocking=True, timeout=timeout)
    if ack is None:
        print("[ERROR] No MISSION_ACK received - upload may have failed")
        return False
    if ack.type == mavutil.mavlink.MAV_MISSION_ACCEPTED:
        print("[OK] Mission upload accepted")
        return True
    print(f"[ERROR] Mission upload rejected (type={ack.type})")
    return False


def set_current_mission_item(master, seq):
    master.mav.mission_set_current_send(master.target_system, master.target_component, seq)
    print(f"[MISSION] Current item set to {seq}")

def set_mode(master, mode_name, timeout=10):
    mode_mapping = master.mode_mapping()
    if mode_mapping is None or mode_name not in mode_mapping:
        print(f"[ERROR] Unknown mode '{mode_name}'")
        return False
    mode_id = mode_mapping[mode_name]
    master.mav.set_mode_send(
        master.target_system,
        mavutil.mavlink.MAV_MODE_FLAG_CUSTOM_MODE_ENABLED,
        mode_id,
    )
    start = time.time()
    while time.time() - start < timeout:
        msg = master.recv_match(type=["HEARTBEAT", "STATUSTEXT"], blocking=True, timeout=timeout)
        if msg is None:
            continue
        if msg.get_type() == "STATUSTEXT":
            print(f"[STATUS] {msg.text}")
            continue
        if mavutil.mode_string_v10(msg) == mode_name:
            print(f"[OK] Mode set to {mode_name}")
            return True
    print(f"[ERROR] Failed to confirm mode change to {mode_name}")
    return False


def arm(master, timeout=10):
    print("[ARM] Arming vehicle...")
    master.mav.command_long_send(
        master.target_system, master.target_component,
        mavutil.mavlink.MAV_CMD_COMPONENT_ARM_DISARM,
        0, 1, 0, 0, 0, 0, 0, 0,
    )
    if not wait_for_ack(master, mavutil.mavlink.MAV_CMD_COMPONENT_ARM_DISARM, timeout):
        return False
    start = time.time()
    while time.time() - start < timeout:
        msg = master.recv_match(type=["HEARTBEAT", "STATUSTEXT"], blocking=True, timeout=timeout)
        if msg is None:
            continue
        if msg.get_type() == "STATUSTEXT":
            print(f"[STATUS] {msg.text}")
            continue
        if bool(msg.base_mode & mavutil.mavlink.MAV_MODE_FLAG_SAFETY_ARMED):
            print("[OK] Vehicle is ARMED")
            return True
    print("[ERROR] Vehicle did not confirm armed state")
    return False


def get_relative_altitude(master, timeout=2):
    latest = None
    end_time = time.time() + timeout
    while time.time() < end_time:
        msg = master.recv_match(type="GLOBAL_POSITION_INT", blocking=True, timeout=0.5)
        if msg is not None:
            latest = msg.relative_alt / 1000.0
    return latest



FENCE_BREACH_TYPES = {
    0: "NONE",
    1: "MINALT",
    2: "MAXALT",
    3: "BOUNDARY",
}


def distance_from_home(home_lat, home_lon, lat, lon):
    """Simple flat-earth approximation - fine for short distances like this."""
    import math
    dlat = (lat - home_lat) * 111320.0
    dlon = (lon - home_lon) * 111320.0 * math.cos(math.radians(home_lat))
    return math.sqrt(dlat ** 2 + dlon ** 2)


def print_fence_status(master):
    """Non-blocking check for a FENCE_STATUS message; prints if one arrived."""
    msg = master.recv_match(type="FENCE_STATUS", blocking=False)
    if msg is None:
        return None
    breached = msg.breach_status != 0
    breach_type = FENCE_BREACH_TYPES.get(msg.breach_type, f"UNKNOWN ({msg.breach_type})")
    if breached:
        print(f"[FENCE] *** BREACH *** (via FENCE_STATUS) type={breach_type} count={msg.breach_count}")
    return breached


def check_fence_health_via_sys_status(master):
    """Fallback breach check: SYS_STATUS reports geofence as an 'unhealthy'
    sensor while breached. Independent of whether FENCE_STATUS is streaming."""
    msg = master.recv_match(type="SYS_STATUS", blocking=False)
    if msg is None:
        return None
    fence_bit = mavutil.mavlink.MAV_SYS_STATUS_GEOFENCE
    present = bool(msg.onboard_control_sensors_present & fence_bit)
    healthy = bool(msg.onboard_control_sensors_health & fence_bit)
    if present and not healthy:
        print("[FENCE] *** BREACH *** (via SYS_STATUS geofence health flag)")
        return True
    return False


def main():
    master = connect()

    enable_throttle_free_auto_takeoff(master)
    configure_geofence(master)

    print("\n[HOME] Reading current position for home placeholder item...")
    home_lat, home_lon = get_current_position(master)
    print(f"        Using ({home_lat:.7f}, {home_lon:.7f})")

    items = build_mission_items(home_lat, home_lon, TAKEOFF_ALTITUDE_M, MISSION_WAYPOINTS)
    if not upload_mission(master, items):
        return

    if not set_mode(master, "GUIDED"):
        return
    if not arm(master):
        return

    print("[WAIT] Settling for 3s before starting the mission...")
    settle_end = time.time() + 3
    while time.time() < settle_end:
        msg = master.recv_match(type="STATUSTEXT", blocking=True, timeout=0.5)
        if msg is not None:
            print(f"[STATUS] {msg.text}")

    set_current_mission_item(master, 1)
    if not set_mode(master, "AUTO"):
        return

    print(f"\n[MISSION] AUTO mode engaged. Waypoints 1-4 stay inside the "
          f"{FENCE_RADIUS_M} m fence; waypoint 5 is deliberately outside it - "
          f"watch for the breach and the mode switching to RTL.\n")

    breach_seen = False
    last_mode = "AUTO"
    start = time.time()
    demo_timeout = 210

    while time.time() - start < demo_timeout:
        if print_fence_status(master):
            breach_seen = True
        if check_fence_health_via_sys_status(master):
            breach_seen = True

        pos = master.recv_match(type="GLOBAL_POSITION_INT", blocking=False)
        if pos is not None:
            alt = pos.relative_alt / 1000.0
            dist = distance_from_home(home_lat, home_lon, pos.lat / 1e7, pos.lon / 1e7)
            print(f"        Altitude: {alt:.2f} m, Distance from home: {dist:.1f} m")

        hb = master.recv_match(type="HEARTBEAT", blocking=False)
        if hb is not None:
            mode = mavutil.mode_string_v10(hb)
            armed = bool(hb.base_mode & mavutil.mavlink.MAV_MODE_FLAG_SAFETY_ARMED)
            if mode != last_mode:
                print(f"[MODE] Changed to {mode}")
                last_mode = mode
            if breach_seen and not armed:
                print("[OK] Vehicle disarmed after fence action - demo complete")
                break

        time.sleep(0.3)
    else:
        print("[WARN] Demo timeout reached without seeing a full fence-action "
              "landing/disarm - check Mission Planner for current status.")

    print("\nGeofence script finished.")
    master.close()


if __name__ == "__main__":
    main()
